# 账户与账本

账户保存名称、期初余额与删除状态，在所有账本间共用。账本组织明细和分类；账单通过稳定 ID 分别引用账本、分类和账户。

## 账户

收入和支出可选择账户及余额影响。转账指定不同的转出与转入账户，转入金额由转出金额、手续费和优惠共同计算。编辑、删除和恢复账单时，事务先撤销旧余额影响，再应用新记录。

已使用账户删除后从日常选择和新记账入口移除，历史明细、账户身份与余额保留。恢复时核对有效账户的名称唯一性。相同名称的新账户拥有独立 ID。

## 账本

选择沿用当前账本与最近成功保存的选择，可指定默认项兜底。删除空账本按有效明细判断，已删除明细的来源凭据保持可追溯。最后一个空账本删除后，在事务中创建一个新账本。

合并预览展示条数、收支及分类去向。提交时重新核对来源和目标状态，同名分类采用目标配置，其他分类随明细移入。引用检查和提交在同一事务中执行。

## 导入

Excel 预览先建立账本、分类与账户映射。账户只匹配有效名称，已删除账户保留历史身份。重复与冲突由来源凭据和内容共同判断，确认后统一写入账目、余额和凭据。

## 兼容

数据库当前为 v8。迁移保留稳定 ID、历史金额、来源与余额信息；来源账户名称发生冲突时生成可区分名称。ZIP v4 保存账户删除状态和分类来源，读取 v1–v4 的兼容测试覆盖旧格式字段补全。
