# 使用说明

## 检查更新

“设置 → 关于”显示当前版本、自动检测开关和“检查更新”。自动检测默认开启，回到应用时每天最多检查一次。关闭后可继续手动检查。

检测分别尝试 Gitee 和 GitHub，采用有效结果中的最新稳定版本。发现更新后可打开发行页；两个源提供相同新版时可选择平台下载。单源失败不打扰使用；两个源都失败时提示稍后重试。下载和安装由浏览器与 Android 完成。

设置中的“分类布局”提供自动、网格和列表。自动模式随界面语言选择，显式选择会跨语言保留。宽窗口中的账单列表与详情并排显示，收窄窗口后保留当前选中账目。

## 日常记账

账单页默认显示当月明细，备注为主要内容，分类图标、交易对象、时间和账户辅助核对。顶栏左侧的账本选择器切换账本，月份入口提供本月、上月、今年、全部时间、年月滚轮和自定义范围。左右箭头按月、年或整段月份切换。账单页的“+”用于新增，账单与统计共用位置稳定的筛选入口，筛选采用漏斗图标。统计页沿用当前账本与筛选条件，点击分类可查看对应明细。

“记一笔”提供支出、收入和转账。分类直接展开，备注可直接输入，手动新增时光标定位在备注。点击金额使用内置数字键盘，时间、账户、账本和交易对象通过标签配置。未沿用其他分类时，使用其他支出或其他收入。转账指定转出与转入账户，手续费和优惠共同决定到账金额。账户余额的变动由表单中的余额选项决定。

统计提供分类排行和收支趋势。趋势图中点击时间点可查看精确金额与笔数，再进入对应月份或月份区间的明细；列表模式用于逐项核对。图表汇总包含当前筛选下的全部账目。

账户与分类在所有账本间共用。新记账必须选择账户，空目录首次提供现金账户。已使用账户删除后从日常选择中移除，历史明细与余额保留，可从“已删除”中恢复。账本合并先展示笔数和金额，再提交事务。

分类页直接显示启用、隐藏两组。长按分类可拖动排序或跨组移动，列表边缘支持连续滚动；“选择”提供批量启用、隐藏、置顶和置底。点击分类修改名称和图标，新增分类与现有项目使用相同操作。恢复默认配置保留自定义分类。目录及用途见[分类](design/CATEGORIES.md)。

## 自动记账

1. 在系统无障碍设置中开启“纯净记账”，允许应用显示悬浮窗。
2. 在应用“设置 → 自动记账”中开启功能。
3. 打开已有微信或支付宝交易详情，核对弹出的金额、分类、账户和时间，再保存。

悬浮窗可收起并保留填写内容。“重复”标记用于核对已存在的记录，保存操作由使用者决定。当前自动识别范围为中文、英文普通人民币收支详情。退款、提现及平台转账页面列入后续适配，账内转账通过手动表单记录。

运行状态、暂停/继续、常驻通知和保存提示集中在自动记账设置中。常驻通知提供暂停、继续和“记一笔”入口。通知被划走后，下次打开应用会检查权限和运行状态，并恢复已开启的通知。应用内开关、系统通知权限和通知渠道共同控制显示。

## 导入与迁移

Excel 导入先读取预览，展示账本、笔数、金额、重复与冲突。核对按名称复用或新建的账本、账户及余额选项后，再确认导入。公式单元格可先在表格软件中粘贴为值。完整表头、字段规则和 AI 转换要求见[从其他账本迁移](IMPORT.md)。

ZIP 数据文件保存账本、账户、分类、账单及导入和识别引用。图片链接随原始记录保留。当前 ZIP 范围为结构化账务数据；设备设置与附件文件单独管理。

## 外观与语言

外观提供跟随系统、浅色和深色。语言提供跟随系统、简体中文、繁體中文、English、日本語。内置分类随语言显示，用户改名和自定义名称保留原文。账本名、账户名、商户和备注按原内容显示。

手机主界面请求竖屏显示；平板和展开后的宽窗口沿用多栏布局。单笔账目的日期、时分仍可精确修改。

后台耗电入口位于“设置 → 自动记账”。进入后在系统页面选择需要的电池管理方式；返回应用后刷新系统状态。
