# 当前状态

公开版本 0.1.0，Android 构建号 60400；包名 io.github.localledger.app，数据库 v9，ZIP 写 v5、读 v1–v5。

## 验证范围

本地检查包括金额与交易语义、数据库迁移、导入和重复处理、界面状态、双源更新、正式签名与公开版本编号策略。远程当前提交的结果以 [main 分支 Verify](https://github.com/LoveElysia1314/pure-ledger/actions/workflows/verify.yml?query=branch%3Amain) 为准。

专用 LocalLedger_API35 模拟器用于覆盖安装、数据与权限保持验证。证书适配范围为 API26–36 的签名检查；实际设备及厂商系统仍需按场景验收。真机支付页面、物理折叠屏及厂商后台不由模拟器结果替代。

## 数据与签名

正式密钥和原密钥副本只保存在私有目录，公开仓库仅包含证书与轮换证明。API26–32 保留原签名，API33 起使用正式签名，并保留同包数据和签名权限继承。具体构建与恢复规则见 [SIGNING.md](SIGNING.md)。

## 已知限制

- 自动识别覆盖中文、英文普通人民币收支详情；退款、提现和平台转账仍需专门适配。
- XLSX 仅接受[指定结构](IMPORT.md)；退款和报销附加资料不会自动生成关联流水。
- ZIP 迁移覆盖结构化账务数据，设备设置、选择偏好和附件文件尚不构成完整备份。
- 新版 XLSX 导出、退款与报销关联列入[后续功能](ROADMAP.md)。

发行包、对应提交源码、校验值与验证记录保存在忽略的 artifacts/；旧开发资料和仓库重置回退副本保存在本地，不作为公开发行内容。
