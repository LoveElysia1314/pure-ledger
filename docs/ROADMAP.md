# 开发路线

## 当前基线

0.1.0 提供日常收支、转账、全局账户与分类、账本、Excel 预览导入、ZIP 数据迁移和普通人民币交易详情候选。分类支持拖动、启用与隐藏两组和批量操作。分类布局按语言和用户偏好切换网格、列表。统计提供分类占比、收支变化与期间钻取，两种分析共用图表／列表偏好；宽窗口账单采用列表和详情双栏，备注直接编辑。浏览期间以月为最小单位，顶栏入口稳定；手机主界面请求竖屏。浏览、录入和管理控件共用色面层级，收支金额采用独立语义色，录入标签按宽度换行。

## 支出关联回款

- 原始支出金额独立保存，退款和报销通过关联明细记录金额、到账账户、实际时间与备注。
- 支持部分、多次回款，累计金额受原支出金额约束；到账、撤销、删除及账户影响采用同一事务。
- 待报销作为支出标记，回款明细推导部分、完成等状态；统计同时明确原账净支出与回款现金流的时间归属。

## 数据迁移

- 将设置、选择偏好和附件文件纳入完整备份，建立恢复引用和失败回滚检查。
- 提供结构清楚的 XLSX 报表，核对金额、日期、账户和分类的往返含义。

## 自动记账

- 按实际页面扩充微信和支付宝解析器，优先补齐稳定、可验证的字段变体。
- 为退款、提现和平台转账分别建立交易模型与反例。
- 持续核对系统重启、服务重绑、通知权限和厂商后台管理的运行场景。

## 浏览与维护

- 维护正式签名、双源更新与版本对应的源码和校验值，保留覆盖升级及远程验证证据。

- 将分类编辑、图标选择与目录浏览组成连续的编辑流程，核对底部抽屉与独立页面在小窗口中的适用性。
- 按真实使用反馈优化筛选、分类浏览、连续录入和大字体布局。
- 保持纯逻辑与 Android 适配层的边界，记录性能样本和兼容结果。
- 按发布流程维护源码、许可证、签名和可复现验证资料。
