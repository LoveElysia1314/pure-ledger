# 微信转账识别

## 从哪里识别

收到好友转账后，打开收款确认页底部的“账单详情 / Transaction Details”。详情中需同时具备付款方、正号金额、已到账状态、转账时间、收款时间和转账单号。

收款确认页和聊天卡片可能缺少付款方、交易单号，英文确认页还可能使用含糊的数字日期。本软件不据此补造凭据；请进入完整账单详情。未领取、待对方收款、已退还、退款或失败状态不会生成收入候选。

## 字段与记账含义

| 内容 | 中文详情 | 英文详情 | 处理方式 |
| --- | --- | --- | --- |
| 付款方 | `转账-来自…` | 页面可能仍保留中文生成标题，也支持 `Transfer from …` | 取明确付款方，不以转账说明代替 |
| 金额 | 正号人民币金额 | 正号人民币金额 | 精确到分，记为收入 |
| 状态 | 当前状态：已存入零钱 | Current Status: Deposited into Balance | 必须明确到账 |
| 发起时间 | 转账时间 | Transfer Time | 核对时间先后关系 |
| 入账时间 | 收款时间 | Received Time | 用作账目时间 |
| 交易身份 | 转账单号 | Transfer Order No. | 使用原始完整单号判断重复 |

支持明确年月日的中文日期及 `yyyy/M/d HH:mm:ss` 等已有日期格式。时间按 `Asia/Shanghai` 解释，保持其他微信人民币详情的时区约定。收款时间不能早于转账时间。

切换微信语言不会改变同一单号的来源身份。重复提示供核对，确认后的账目、账户余额和来源凭据在同一事务中保存。两笔金额、付款方及时间相同但单号不同的转账仍为两笔交易。

本次仅新增收到的转账。红包、发出的聊天转账、退还款和跨币种交易仍需分别适配。

## 官方文档调研

查阅日期：2026-11-05。

微信提供[商家转账产品文档](https://pay.wechatpay.cn/doc/v3/merchant/4012711988)和[查询红包记录接口](https://pay.wechatpay.cn/doc/v2/merchant/4011981612)。前者围绕商户发起的转账及其查询，后者要求商户号、商户订单号和商户证书，用于查询商户发放的红包。它们不能直接充当个人好友转账或聊天红包的账单读取接口。

本次在公开开发文档中未找到个人好友转账详情页的字段规范或面向记账软件的个人账单读取接口。因此，当前适配依据指定设备的中英文页面，使用本地无障碍快照解析；不接入商户接口、不读取微信私有数据库，也不将个人账单发往服务器。页面或微信版本变化后，仍需按实际字段复核。

真实页面只保留在本地私有目录。公开回归使用合成付款方、金额、时间和单号，覆盖中英文、待收款、退还、缺失与冲突字段、重复触发和相似交易。
